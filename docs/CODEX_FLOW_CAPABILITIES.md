# Codex Flow Capabilities

Codex Flow treats media systems as platform capabilities, not separate business
skill systems.

Planned capability areas:

- `image`
- `video`
- `audio`
- `edit`
- `ui`

Business skills describe creative intent and quality rules. Capability modules
own media-specific input preparation, execution boundaries, idempotency, paid
gates, technical failure handling, and output registration.
