# Scene Storyboard Grid

## Core Task

将一张场景底图，或一张场景底图加一张主体整体设定图，编写为主体身份、场景几何、建筑遮挡、材质、光影和时间连续的单张 3×3 九宫格图片分镜提示词。用于九宫格分镜、3×3 storyboard、场景拆镜、镜头拆解、特写组图，或需要在不同机位中严格保持 Logo、产品、人物、雕塑、装置、建筑模型等主体一致性时。
