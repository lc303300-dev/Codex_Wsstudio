# 参考图风格重绘

用于用户同时提供目标图与风格参考图，并要求重绘、风格迁移或统一视觉语言的图片任务。

1. 将目标图设为内容与构图锚点，保留其主体身份、构图和空间关系。
2. 将参考图仅视作视觉语言来源：色彩、光线、材质、笔触、渲染密度与氛围可迁移；其主体、构图、文字不可迁移。
3. 生成模型无关的 ImageSpec。需要补充风格结构时，查询社区图像原型；选中原型后再检索至多五个带来源的案例，只提炼可泛化的视觉约束。
4. 要求用户明确选择支持的图片比例后，才可进入统一图片路由。不得在本 Skill 中指定提供商、模型或私有执行参数。
