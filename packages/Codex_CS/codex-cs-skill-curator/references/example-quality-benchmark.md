# 视频 Skill 范例质量基准

本基准从正式库中结构较完整的 Skill 提炼，只规定审核维度和表达完整度，不复制题材内容，也不得用于推断素材契约。

## 基准来源

- `giant-ip-landmark-parade`：完整输入、完整成片提示词、逐镜时间段、主体表演与物理反馈。
- `sci-fi-city-promo`：输入到输出的完整映射、统一视觉主线、逐镜推进和质量检查。
- `architectural-assembly-reveal`：单镜头的空间方向、动作轨迹、接触顺序、可见结果和停止状态。

来源 Skill 只提供质量尺度。城市、人物、建筑、Logo、镜头数量、转场方式和视觉风格不得迁移到其他 Skill，除非目标 Skill 自身来源明确支持。

## 完整正例

每个 Skill 至少需要一项完整正例。正例必须包含：

1. 输入条件：说明使用哪些契约槽、时长、比例及必要用户意图；不能新增契约要求。
2. 参考绑定：素材编号、顺序和业务角色清晰。
3. 全局设定：主体身份、场景、材质、光色、视觉主线和连续性要求。
4. 时间推进：按时段或清晰的先后关系写出画面变化。
5. 摄影机与主体：分别描述摄影机运动和主体动作。
6. 物理结果：需要交互时写明轨迹、接触、受力、遮挡、形变和停止状态。
7. 结尾条件：最终构图、主体状态、光线或严格首尾帧关系明确。
8. 约束：只保留与当前 Skill 和当前示例有关的风险约束。
9. 可执行性：不得使用“自然变化”“适当运动”“根据画面选择”等代理式占位语句。

## 反例

每个 Skill 至少需要一项反例，并同时记录：

- 错误写法或失败提示词片段；
- 违反的目标 Skill 规则；
- 可观察的失败表现；
- 修正策略或合格改写方向。

不得只列负面关键词。

## 边界案例

每个 Skill 至少需要一项边界案例，并同时记录：

- 触发条件；
- 哪些来源规则仍然适用；
- 哪些默认做法应停止或降级；
- 应如何向用户询问、保留原意或安全处理。

典型边界包括素材语义不明、用户提供完整提示词、用户规则覆盖默认规则、严格首尾帧与普通场景参考冲突等，但具体案例必须与目标 Skill 自身契约一致。

## 质量检查

审核正例时至少检查：

1. 契约槽与素材编号是否一致；
2. 是否保持用户指令最高优先级；
3. 是否有可见主体、动作、摄影机、环境、光色、物理和结尾；
4. 是否避免题材外规则、旧 provider、模型、分辨率和执行命令；
5. 是否能直接用于指导同类任务，而非只有抽象原则；
6. 反例是否有原因与修正；
7. 边界案例是否有条件与处理；
8. 示例是否只辅助理解，没有定义或改变契约。
