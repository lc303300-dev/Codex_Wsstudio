# 建筑特写至全貌动态组装展示视频提示词生成 Skill

## name
建筑特写至全貌动态组装展示视频提示词生成 Skill

## description
将建筑外观、构造节点、室内、露台、庭院等多张参考图，转换为可直接提交给视频模型的逐镜头中文提示词。适用于从建筑特写逐步展示到完整全貌，并表现结构件拆解后重新咬合、可见家具或道具倾斜降落放平、真实材质光影流转以及快—慢—快复合运镜。每张参考图作为对应五秒镜头在最后一刻必须抵达的绝对尾帧。

## 输入要求

必须先获得：

1. 视频时长：四至三十秒；优先按五秒规划镜头，末镜允许使用不足五秒的剩余时长。
2. 画面比例。
3. 与镜头数量一致的场景参考图：原则上每个完整五秒镜头一张，末镜不足五秒时仍可对应一张；图片、视频和音频/音乐参考合计最多50项。
4. 每张参考图的真实视觉观察：可见建筑构件、家具或道具、环境元素、材质、光源方向、遮挡关系与最终构图。

若信息不足，只索要缺失信息，不生成提示词。

## 核心生成原则

### 一、先实例化，后写提示词

必须先在后台为每个镜头确定以下内容，再组织自然语言：

- 具体画面主体：使用参考图中真实可见的构件名称，如石材墙板、金属檐口、玻璃栏板、雨棚支臂、门扇、餐桌或编织椅。
- 具体装配目标：写清主体要进入的墙槽、框架、连接件、承托面、地面位置或最终家具位置。
- 具体运动轨迹：明确从画面的哪一侧、哪个前后层级或哪个高低方向运动到哪里。
- 具体接触顺序：写清先插入、再旋紧、再压合，或先触地、再回正、再停止。
- 具体物理结果：写清哪条接缝被遮住、阴影落在哪里、反射如何移动、哪个部件受重力下沉后停止。
- 具体镜头路径：明确起幅、中段和落幅分别怎样推进、平移、抬升、下降或环绕，只能选定动作，不能列出动作菜单。
- 具体焦点与构图锚点：写清焦点锁定哪个构件、哪个连接处或哪一条立面边缘。
- 具体尾帧状态：最后一刻镜头正好抵达参考图的机位、构图、主体位置和光影状态。

必须把上述决定直接写进成品提示词。严禁把决策任务留给视频模型或后续 Agent。

### 二、镜头运动必须明确，但不得数字化

每个镜头必须采用“快速起幅—缓慢水平展示—快速落幅”的三段式复合运镜；不足五秒的末镜按比例压缩节奏，但保留完整起幅、展示与落幅。

每段必须写出唯一且明确的方向和动作，例如“快速向前推进并顺时针绕向建筑右侧”“保持水平视角向右平移并继续顺时针微旋”“沿相同轴向快速推进并顺时针收束”。

镜头运动严禁出现距离、角度、焦距、速度倍率、机位高度等具体数字参数。可以使用“近距离、轻微、短促、缓慢、明显、低机位、仰视、水平视角”等自然语言量级。

起幅与落幅必须保持相同的平移轴向和旋转方向，但速度、幅度和构图任务可以不同。中段必须尽量保持水平视角和稳定运动。

相邻镜头必须至少延续一项同向运动。必须在每个镜头中直接写出延续的是哪个方向，不得写“保持一项同向动作”。

### 三、组装动作必须绑定具体构件

建筑结构或硬装只能沿符合构造关系的装配路径运动：墙板进入墙槽，钢架对准节点，玻璃栏板连接件沿孔位插入，雨棚支臂绕连接轴归位，檐口沿收口方向压合。严禁只写“向中心拼装”“自然组合”“完成生长”。

每个镜头必须至少写出一个具体构件、一个具体目标位置、一个清晰轨迹和一个接触后的可见结果。

仅当参考图中真实可见家具或可移动道具时，才使用软装规则：物件以倾斜姿态沿斜向轨迹下降，先由一侧或支点接触承托面，再缓慢放平或回正，受重力产生轻微沉降或回弹后稳定。严禁给纯建筑外立面、构造节点或空场景凭空增加家具。

不得让同一镜头中的所有部件同时、同速、同方向飞行。必须选择前景、中景或主体结构中的少量关键部件，按可理解的先后顺序完成装配。

### 四、时间与绝对尾帧

每个镜头必须明确写出起幅阶段、中段展示阶段和落幅阶段的时间范围。时间数字只用于视频分段，不属于镜头运动参数。

参考图必须作为该镜头最后一刻的绝对尾帧。组装动作先完成锁定，落幅运动随后沿既定方向收束，并在镜头终点准确抵达参考图机位和构图。严禁先抵达参考图，再继续冲出参考构图。

### 五、材质与环境必须来自观察

必须根据参考图中已经观察到的材质写光影变化：玻璃可出现环境反射和边缘高光，金属可出现窄幅高光移动，粗糙石材保持漫反射，木材与布艺保持柔和哑光。

只有参考图存在明确强光源且材质与角度成立时，才允许写镜头光斑或辉光；否则不写。严禁默认给每个镜头添加 Glow、Lens Flare、霓虹或镜面反射。

背景动态只能使用参考图中真实可见的元素，并写出具体对象和方向，如树叶向右轻摆、云影沿立面缓慢移动、玻璃中的天空反射随镜头向左滑动。严禁写“背景持续活化”“可运动元素自然变化”。

### 六、禁止代理指令与模板泄漏

最终提示词严禁出现以下类型的文字：

- “主体围绕画面中最适合互动的……”
- “产生可见接触、遮挡、投影、受力、惯性或环境扰动”
- “镜头根据场景选择推进、平移、环绕、俯冲或拉远”
- “背景中可运动元素持续活化”
- “动作A”“动作B”“描述原图具体材质”“提取一个同向动作”
- “例如”“如适用”“重复上述”“以此类推”“合理选择”“适当运动”
- 任何方括号占位符、未选定的并列动作菜单或要求后续模型自行判断的元指令

若草稿出现上述内容，必须在后台重写对应镜头，不能输出不完整草稿。

## 工作流程

1. 校验时长、比例、图片数量和观察记录。
2. 按参考图顺序规划从特写到全貌的镜头关系。
3. 为每镜选择一个唯一复合运镜，并明确起幅、中段、落幅及焦点锚点。
4. 从观察记录中选出少量真实可见构件，写明装配目标、轨迹、接触顺序和停止条件。
5. 仅对真实可见的家具或道具写倾斜降落放平。
6. 仅对真实可见的背景元素和材质写动态与光影反馈。
7. 将每个镜头完整展开，不引用前文，不使用“重复上述”。
8. 静默执行质量检查；不合格则重写。
9. 最终只输出可直接复制的视频提示词，不输出分析过程或 Markdown 说明。

## 最终输出结构

【视频提示词】

画面比例：用户指定比例　视频时长：用户指定时长

参考素材说明：逐一说明每张图片对应的五秒镜头，并明确它是该镜头最后一刻的绝对尾帧。

全局要求：简要说明真实材质、主体连续性、快—慢—快复合运镜、相邻镜头方向衔接和尾帧约束。不得在全局要求中用抽象句代替逐镜具体动作。

逐镜头段落必须完整包含：

1. 参考图中可见场景、构件和材质。
2. 开场的半拆解状态与明确失焦对象。
3. 起幅阶段的唯一复合运镜、方向和焦点变化。
4. 中段的水平稳定运镜与焦点锚点。
5. 具体构件的起点、轨迹、装配目标、接触顺序和物理结果。
6. 仅在可见时写家具或道具的倾斜降落放平。
7. 具体背景对象和具体方向的轻微动态。
8. 落幅阶段与起幅一致的轴向和旋转方向。
9. 最后一刻准确抵达对应参考图构图。

整体要求：只总结已经在逐镜中写明的规则，不新增抽象任务。

负面约束：针对本次画面中真实可能发生的问题编写，不复制通用长列表。

## 合格镜头写法示例

画面以石材立面、深色金属檐口和玻璃栏板的失焦轮廓开场。起幅阶段，镜头从低机位快速向前推进，同时顺时针绕向建筑右侧，前景檐口掠过画面上缘形成短暂动态模糊，焦点迅速落在玻璃栏板与金属檐口的接缝。中段，镜头保持仰视但维持水平高度，缓慢向右平移并继续顺时针微旋，焦点始终锁定栏板连接处。右侧悬挑板从画面左后方沿右前方斜向轨迹靠近墙体，先让金属连接件插入预留槽，再让石材边缘压合到位；接触后栏板边缘遮住墙缝，并在浅灰石材上投下窄而清晰的阴影，构件受重力轻微下沉后停止。落幅阶段，镜头沿起幅相同的推进轴向和顺时针方向快速收束，在最后一刻准确抵达参考图的近距离仰视构图，所有结构、遮挡、反射和光照与参考图一致。

该示例只说明具体化程度，不得作为固定模板复制到不相符的场景。

## 静默质量检查

输出前必须逐镜检查：

1. 是否点名了参考图中真实可见的具体构件和装配目标？
2. 是否写出了起点、方向、轨迹、接触顺序、可见结果和停止状态？
3. 是否把运镜写成唯一选定动作，而不是动作菜单？
4. 是否明确写出起幅、中段和落幅的方向、视角与焦点锚点？
5. 镜头运动是否完全没有距离、角度、焦距、速度倍率和机位高度数字？
6. 起幅与落幅是否保持相同轴向和旋转方向？
7. 相邻镜头是否直接写明了延续的同向运动？
8. 是否只对真实可见的家具或道具使用倾斜降落放平？
9. 是否只对真实可见的背景元素和材质写动态与光影？
10. 最后一刻是否准确抵达对应参考图，而不是抵达后继续移出？
11. 是否完整展开每个镜头，没有“重复上述”“如适用”或任何占位符？
12. 是否没有出现“最适合互动”“根据场景选择”“可运动元素持续活化”等代理指令？

任一项不满足，必须重写该镜头后再输出。

## 确认机制

输出完整提示词后，等待用户确认。只有用户确认提示词并选择视频模型与分辨率后，才能进入视频生成阶段。
