# 科幻风格城市宣传片提示词生成 Skill

## name
科幻风格城市宣传片提示词生成 Skill

## description
将用户提供的城市名称、视频时长、画面比例和按任务需要配置的城市地标参考素材，转化为“科幻城市宣传片”视频提示词。

该 Skill 擅长生成“未来城市 + 地标建筑 + 地方文化 + 数字光流 + 电影级一镜到底”的城市宣传片提示词。默认风格为 UE5 电影级写实渲染、8K 超高清、光线追踪全局光照、黄金时刻暖金色阳光、发光金色丝线贯穿全片、无缝一镜到底运镜，适合制作 4-30 秒城市宣传片、文旅宣传片、城市形象片、城市地标视觉短片。

---

## 最重要的执行规则

当用户只给出笼统指令时，例如：

- “帮我生成一个城市宣传片视频”
- “做一个城市宣传片提示词”
- “生成城市宣传片”
- “用这个 Skill 帮我做城市宣传片”

不要立刻生成完整提示词。

必须先向用户索要以下必填信息：

1. 城市名字。
2. 视频时长，必须在 4-30 秒之间。
3. 画面比例，例如 16:9、9:16、3:4、1:1。
4. 按叙事需要提供城市参考素材，建议包括城市地标、现代建筑、历史文化建筑、江河湖海或城市天际线；图片、视频和音频/音乐合计最多50项。

只有在用户至少提供以上 4 类信息后，才可以生成最终视频提示词。

如果用户没有提供图片，只能先询问用户上传图片，不要直接编造图 1、图 2、图 3。
如果用户明确说“没有图片，也要直接生成”，才可以根据城市公开地标进行通用创作，但必须说明这是无参考图版本。

```text

1. 城市名字：
2. 视频时长：4-30 秒，建议 10 秒、15 秒、20 秒或 30 秒
3. 画面比例：例如 16:9、9:16、3:4
4. 请按叙事需要上传参考素材（图片、视频和音频/音乐合计最多50项）：

   - 图2：现代地标建筑
   - 图3：历史文化建筑或地方文化元素

   - 图5：可选，城市最有代表性的视觉符号

```

不要在信息不足时输出最终视频提示词。

## 适用场景

适用于以下任务：

1. 生成 4-30 秒城市宣传片视频提示词。
2. 根据 3-5 张城市地标图，生成一镜到底城市宣传片。
3. 将城市的现代建筑、历史文化、自然景观、江河湖海、夜景天际线融合成科幻视觉叙事。
4. 制作图生视频或多模态视频提示词。
5. 制作文旅宣传片、城市形象片、城市地标短片、城市 IP 宣传短视频。
6. 将“普通城市素材”包装成具有电影感、未来感、史诗感的城市宣传片。

---

## 不适用场景

不适用于以下任务：

1. 需要严格还原城市真实地理位置和道路走向的纪录片。
2. 需要精确表现城市规划、交通路线、地图信息的说明片。
3. 需要大量人物采访、口播、对白的城市纪录片。
4. 需要完全写实、无任何科幻视觉加工的新闻画面。
5. 需要长篇城市旅游攻略、景点介绍文案、实拍分镜脚本的任务。

## 输入要求

### 必填信息

用户必须提供：

1. 城市名字
例如：广州、深圳、上海、成都、重庆、杭州、西安、昆明、北京。

2. 视频时长
必须为 4-30 秒。
如果用户没有指定，询问用户。
如果用户给出范围外时长，要求调整到 4-30 秒；范围内不因固定模型版本收窄。

3. 画面比例
例如：16:9、9:16、3:4、1:1。
如果用户没有指定，询问用户。
小红书竖版笔记建议使用 3:4 或 9:16。
横版宣传片建议使用 16:9。

4. 按叙事需要提供参考素材；图片、视频和音频/音乐合计最多50项
建议用户按以下类型提供：
- 图1：城市天际线、城市全景、江河湖海或开场大场景。
- 图2：现代地标建筑。
- 图3：文化地标、历史建筑、传统街区或地方文化元素。
- 图4：桥梁、道路、广场、夜景或城市中轴线。
- 图5：可选，城市最有代表性的符号，如塔、山、水、古城门、艺术建筑、博物馆等。

### 可选信息

用户可以补充：

1. 城市宣传主题
例如：未来之城、千年古都、山水之城、科技之城、海滨之城、烟火之城、商都、文旅城市。

2. 视觉主线
例如：金色丝线、蓝色数据光流、水墨粒子、星光粒子、红色灯笼光、城市道路光轨。

3. 色彩风格
例如：暖金夕阳、蓝金科技、赛博霓虹、东方水墨、银蓝未来、青绿山水。

4. 收尾文案或城市口号
例如：“千年商都，未来羊城”“山水重庆，未来之城”。
注意：视频生成模型容易生成文字乱码，如需文字，建议在后期加字。提示词中可以描述“形成主题感收尾”，但不要强制模型生成清晰文字。

## 核心创作理念

这个 Skill 的核心不是简单罗列城市地标，而是把城市宣传片设计成一条“城市被数字能量唤醒”的视觉叙事。

默认叙事结构：

1. 从抽象能量开场
如黑暗背景、金色丝线、数字粒子、水波纹、城市道路光流。

2. 生成城市现代地标
通过金色丝线、数字光流、粒子辉光勾勒城市天际线或现代地标。

3. 切入城市艺术建筑或核心公共空间
展示城市美学、现代化、创新气质。

4. 过渡到历史文化空间
将地方文化、古建筑、传统纹样、历史文脉与科幻视觉结合。

5. 高空拉升形成城市整体画卷
多个地标被光流连接，城市道路、江河、桥梁、天际线同步展开，形成史诗级收尾。

## 核心工作流程

执行任务时，按以下流程生成提示词。

### 第一步：检查信息是否完整

检查用户是否提供：

1. 城市名字。
2. 视频时长。
3. 画面比例。
4. 3-5 张参考图片。

如果缺少任何一项，先询问，不生成最终提示词。

---

### 第二步：识别城市宣传片的核心视觉资产

从用户输入和图片说明中提取以下信息：

1. 城市现代地标
如城市塔、CBD、大剧院、博物馆、艺术中心、摩天楼、科技园区。

2. 城市历史文化地标
如古城墙、祠堂、寺庙、老街、传统建筑、地方文化街区、非遗纹样。

3. 城市自然景观
如江河、湖泊、海岸线、山脉、湿地、森林、公园。

4. 城市空间结构
如中轴线、跨江桥梁、道路光流、城市广场、滨江岸线、天际线。

5. 城市气质关键词
如千年古都、未来科技、山水城市、海滨城市、烟火城市、国际商都、艺术之城。

---

### 第三步：选择视觉主线

默认使用“发光金色丝线”作为全片视觉主线。

发光金色丝线的作用：

1. 串联不同地标。
2. 让不同图片之间形成无缝过渡。
3. 将城市历史、文化、建筑、道路、江河抽象成统一视觉语言。
4. 强化高级感、史诗感、科技感。
5. 降低不同参考图之间风格不一致的问题。

如果城市更适合其他视觉主线，可以替换：

- 海滨城市：蓝金水流光带。
- 古都城市：金色丝线 + 水墨粒子。
- 山水城市：青绿色光流 + 云雾。
- 赛博城市：蓝紫霓虹数据流。
- 红色文化城市：红金粒子光带。
- 雪山城市：银白光流 + 冰晶粒子。

---

### 第四步：设计一镜到底空间路径

将 3-5 张图片组织成连续镜头，不要做生硬跳切。

默认空间路径：

1. 抽象能量开场。
2. 从城市水脉、道路、桥梁、地基纹理中生成城市。
3. 第一个重点地标出现，通常使用图 1 或图 2。
4. 镜头推进、环绕或俯冲，过渡到第二个地标。
5. 通过体积雾、光流、粒子、水面倒影或道路光轨过渡到第三个地标。
6. 镜头快速拉升，多个地标被视觉主线连接，形成城市整体画卷。
7. 最后定格在城市天际线、城市地标群或象征性收尾画面。

---

### 第五步：按时长拆分时间段

根据用户提供的时长拆分镜头。

#### 5 秒版本

适合极短视频，只保留 3 段：

1. 0-1.5 秒：金色丝线 / 城市能量开场。
2. 1.5-3.5 秒：重点地标生成与环绕。
3. 3.5-5 秒：城市整体拉升收尾。

#### 8 秒版本

适合短促震撼版本：

1. 0-2 秒：抽象能量开场。
2. 2-4 秒：第一个重点地标生成。
3. 4-6 秒：第二个地标或文化空间生成。
4. 6-8 秒：城市整体拉升收尾。

#### 10 秒版本

适合平台短视频常用版本：

1. 0-2 秒：抽象能量开场。
2. 2-4 秒：现代地标生成。
3. 4-6 秒：艺术建筑 / 城市核心空间生成。
4. 6-8 秒：历史文化地标生成。
5. 8-10 秒：城市整体拉升收尾。

#### 12 秒版本

1. 0-3 秒：抽象能量开场。
2. 3-5 秒：现代地标生成。
3. 5-7 秒：城市核心空间 / 艺术建筑生成。
4. 7-10 秒：历史文化或自然景观生成。
5. 10-12 秒：城市整体拉升收尾。

#### 15 秒版本

1. 0-4 秒：抽象能量开场，城市脉络被唤醒。
2. 4-7 秒：第一个重点地标生成。
3. 7-10 秒：第二个重点地标生成。
4. 10-12 秒：第三个重点地标或历史文化空间生成。
5. 12-15 秒：多个地标被光流连接，高空拉升，形成城市史诗收尾。

---

### 第六步：强化无缝一镜到底

必须使用以下衔接方式之一或多个：

- 金色丝线从一个地标延伸到另一个地标。
- 镜头穿过暖金色体积雾。
- 镜头掠过江河水面倒影。
- 镜头沿城市道路光流高速推进。
- 镜头穿过桥梁结构或建筑缝隙。
- 粒子辉光在画面中扩散，转化为下一个场景。
- 建筑线框逐渐实体化，再转化为真实材质。
- 从建筑纹理、屋脊纹样、玻璃幕墙或道路网格中自然过渡。

不要写“切换到下一个画面”。
应该写“无缝推进”“穿过体积雾”“沿光流进入”“从线框转化为真实建筑”。

---

### 第七步：强化城市文化表达

根据城市特点加入文化信息，但要转化为视觉画面。

不要只写：

```text
体现城市文化底蕴。
```

要写成：

```text
金色丝线从屋脊、砖雕、木雕、传统纹样中扩散，逐步点亮历史建筑立面，古建材质由线框转化为真实青砖、木构、陶塑纹理。
```

常见城市文化视觉化方法：

1. 古都：城墙、宫殿、鼓楼、古街、碑刻、青砖、瓦当、屋脊、灯笼。
2. 山水城市：云雾、江水、群山、桥梁、坡地道路、层叠楼群。
3. 海滨城市：海浪、港口、跨海大桥、帆船、海岸天际线。
4. 商都：道路光流、江河货运意象、现代 CBD、灯火、城市脉络。
5. 艺术城市：剧院、博物馆、公共艺术、光影装置、建筑几何线条。
6. 科技城市：数据光流、玻璃幕墙、科技园区、无人机视角、数字孪生城市。

当用户提供城市、时长、比例和 3 张以上图片后，按以下模板改写：

```text

画面比例：【用户提供比例】
视频时长：【用户提供时长】

UE5 电影级写实渲染，【城市名】未来都市美学，发光金色丝线贯穿全片，黄金时刻暖金色阳光，8K 超高清，全程无缝一镜到底运镜，前后元素自然衔接，无穿模、无跳切，光线追踪全局光照，超精细建筑纹理，大气体积雾，电影级调色，史诗氛围，细节拉满布光，浅景深，未来科技感与【城市名】的【地方文化 / 城市气质】深度融合。画面重点融入【图1视觉元素】、【图2视觉元素】、【图3视觉元素】等地标与城市空间，形成“未来都市 + 城市地标 + 地方文化”的科幻视觉叙事。

【按用户时长拆分时间段】

第一段：纯黑背景或城市暗部空间，极端特写。发光金色丝线在黑暗中缓缓游走、旋转、交织，先编织出【城市水脉 / 道路脉络 / 桥梁结构 / 地基纹理】。粒子辉光细密闪烁，仿佛数字能量正在唤醒整座【城市名】。镜头贴近丝线运动，水面反光、金属节点、玻璃幕墙纹理逐渐显现，呈现电影级科技质感。
```

## 质量检查清单

生成最终提示词前，必须检查：

1. 是否已经获得城市名字？
2. 是否已经获得 4-30 秒之间的视频时长？
3. 是否已经获得画面比例？
4. 是否已经获得 3-5 张参考图片，或用户明确允许无图生成？
5. 是否按时长拆分了合理时间段？
6. 是否有清晰的城市视觉主线？
7. 是否有至少 2-3 个城市重点视觉元素？
8. 是否体现了城市现代面貌？
9. 是否体现了地方文化或城市气质？
10. 是否明确写出无缝一镜到底？
11. 是否避免生硬跳切？
12. 是否避免让模型生成乱码文字？
13. 是否避免随机编造不属于该城市的地标？
14. 是否适合直接复制使用？

如果第 1-4 项缺失，不要生成最终提示词，必须先询问用户补充信息。

## 常见失败案例与修正方法

### 失败案例 1：用户信息不足就直接生成

错误行为：

```text
用户：生成一个城市宣传片。
助手：直接输出完整城市宣传片提示词。
```

修正方法：

必须先询问城市、时长、比例、参考图片。

---

### 失败案例 2：城市地标堆砌，没有视觉主线

错误写法：

```text
画面出现广州塔、陈家祠、珠江、广州大剧院、白云山、北京路。
```

修正方法：

用金色丝线、数字光流、江河水脉或道路光轨串联所有元素，让地标之间有因果和运动衔接。

---

### 失败案例 3：只写城市高级感，没有画面细节

错误写法：

```text
广州很高级，很科幻，很有文化底蕴。
```

修正方法：

改成可拍摄画面：

```text
金色丝线从珠江水波纹理中升起，沿广州塔网格钢结构向上攀升，暖金夕阳穿透塔身，珠江水面反射出城市天际线。
```

---

### 失败案例 4：生硬切换场景

错误写法：

```text
接着切换到陈家祠。
```

修正方法：

改成无缝过渡：

```text
镜头穿过一层暖金色体积雾，金色丝线从现代 CBD 的玻璃幕墙纹理延伸到古建屋脊纹样，场景自然过渡到陈家祠。
```

---

### 失败案例 5：强制模型生成文字导致乱码

错误写法：

```text
画面上出现清晰文字“千年商都，未来羊城”。
```

修正方法：

改成：

```text
形成“千年商都，未来羊城”的主题感收尾，具体文字建议后期添加，画面中不要生成大段文字。
```

## 执行原则

1. 信息不足时，先询问，不要生成。
2. 用户只给笼统需求时，必须让用户填写城市名字、时长、画面比例，并上传 3-5 张参考图片。
3. 最终输出要能直接复制使用。
4. 优先保证视频模型可执行，不要堆砌过多抽象形容词。
5. 优先保证地标识别度，不要过度改变参考图建筑轮廓。
6. 优先保证无缝一镜到底，不要写“切换镜头”。
7. 用统一视觉主线串联所有参考图。
8. 城市文化必须转化成视觉元素，而不是空泛表达。
9. 对于 4-30 秒视频，每个时间段只安排一个核心画面任务。
10. 结尾必须形成城市整体画卷、天际线、地标群或城市主题感收尾。
